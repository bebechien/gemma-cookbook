# Join the Google Developer Community Discord

Are you interested in chatting with Googlers and other developers about using
Gemma? Join the
[Google Developer Community](https://discord.gg/google-dev-community)
Discord server! This is a great place to interact with developers, and to learn,
share, and support each other.

You can find us in the `#gemma` channel in the "All things AI" section. See
you there!

Tip: If you're new to Discord, check out this
[beginner guide](https://support.discord.com/hc/en-us/articles/360045138571-Beginner-s-Guide-to-Discord)
to familiarize yourself with the platform.
